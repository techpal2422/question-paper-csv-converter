# Question Paper → CSV Converter

Upload a Word `.docx`, enter the question group/type/level/marks, preview the extracted questions, and download CSV.

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Free deployment
Use Streamlit Community Cloud:
1. Create a GitHub repository.
2. Upload `app.py` and `requirements.txt`.
3. Go to https://share.streamlit.io/
4. Sign in with GitHub and connect the repository.
5. Create an app using `app.py` on the `main` branch.
6. Deploy and share the generated `streamlit.app` URL.
